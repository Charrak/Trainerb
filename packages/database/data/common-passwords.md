`common-passwords.txt.gz` ist die unveränderte Sperrliste aus [Django 5.2.x](https://github.com/django/django/blob/33d2e5948a0bd365d1f41901bf7e44ec25ec6101/django/contrib/auth/common-passwords.txt.gz), Lizenz siehe `LICENSE-Django`. Bei einem Update den Upstream-Stand und die Produktions-Konfigurationstests mit aktualisieren. Die API benötigt beim Start keinen Netzwerkzugriff. Die kurze `common-passwords.txt` ergänzt die Basisliste um die projektspezifischen Sperren.
